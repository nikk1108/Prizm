# Prizm — Technical Scholar Discovery Portal

A developer-focused knowledge discovery platform for engineers, researchers, and creators to explore technical resources, research, projects, and opportunities through a unified workspace.

**Live Demo:** https://prizm-snowy.vercel.app/  
**Repository:** https://github.com/nikk1108/Prizm

## Overview

Prizm aims to make technical knowledge easier to discover and organize through a structured platform built around research, learning resources, projects, events, and career opportunities.

## Features

- **Research Explorer** — Discover scientific articles, browse abstracts, and access available PDF resources.
- **Resource Library** — Explore courses, technical books, cheat sheets, and useful GitHub repositories.
- **Project Showcase** — Present projects with technology tags and system architecture information.
- **Events Calendar** — Discover workshops, hackathons, and technical meetups.
- **Jobs Portal** — Explore internship opportunities and research funding opportunities.
- **Authentication** — Dedicated login and registration experiences.
- **Post Management** — Create, edit, duplicate, and delete posts.
- **Moderation** — Reporting workflows and moderation logs.
- **Responsive UI** — Editorial-inspired design with copper accents, IBM Plex typography, and dark-mode support.

## Tech Stack

- **Frontend:** React, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Architecture:** REST APIs, reusable UI components, protected routes

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/nikk1108/Prizm.git
   cd Prizm
   ```

2. Install dependencies in the frontend and backend directories according to the project structure.
3. Configure the required environment variables using the project's configuration files.
4. Start the frontend and backend using their respective development scripts.
