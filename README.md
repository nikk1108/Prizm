# Prizm — Technical Scholar Discovery Portal

Prizm is a premium, developer-focused technical scholar portal and knowledge discovery network for engineers, researchers, and creators.

## Key Features

- **Copper Theme & IBM Plex Typography:** High contrast editorial design with micro-interactions, responsive sizing, and dark mode support.
- **Split Screen Auth Flows:** Minimal login/register page split-screen layouts.
- **Dedicated Feeds & Workspaces:**
  - **Research Explorer:** Access scientific articles, abstract previews, and PDF specs.
  - **Resource Library:** Reference courses, cheat sheets, books, and github repos.
  - **Project Showcase:** Interactive framework stack tagging and system architecture blueprinting.
  - **Events Calendar:** Workshops, hackathons, and global meetups.
  - **Jobs Portal:** Internship postings and grant stipends database.
- **Robust Post Management:** Edit, duplicate as draft copy, delete with toast popups, report moderation logs, and clipboard sharing.
